## 4. 画面：予測の実行（DEMO）

DEMO は毎回同じ疑似データなので、数値まで一致するかで回帰確認ができます。

### 4-A. 既定の設定（拡張特徴量 + ウォークフォワード）

| # | 操作 | 期待結果 | 結果 | 備考 |
|---|---|---|---|---|
| 4-1 | `DEMO`・5年・既定の設定で「予測する」 | 実行中はボタンが「計算中…」になり、押せなくなる（数秒かかる） | | |
| 4-2 | 結果の見出し | 「デモ銘柄（疑似データ）」と、横に `DEMO` のバッジ | | |
| 4-3 | 見出しの下の条件表示 | 「検証：ウォークフォワード（20営業日ごとに再学習・計22回）」「特徴量：拡張 24個」「市場指数：DEMO_INDEX」 | | |
| 4-4 | 予測カードの数値 | 上がる確率 **50.2%**、正解率 **49.5%**、ベースライン **50.7%** | | |
| 4-5 | 予測カードの説明文 | 「モデルの正解率がこれを下回っています」 | | |
| 4-6 | 株価チャート | 直近約2年分の折れ線が表示され、マウスを乗せると日付と終値が出る | | |
| 4-7 | バックテストの数値 | モデル戦略 **-10.1%**（赤）、買い持ち **10.9%**（緑）、売買回数 **183回** | | |
| 4-8 | バックテストのチャート | 「モデル戦略」と「買い持ち」の2本の線と凡例が表示される | | |
| 4-9 | バックテストの注記 | 「最初の学習期間: …。以降は20営業日ごとに…学習し直しています。」と表示される | | |

### 4-B. 設定を切り替えて比べる

| # | 特徴量 / 検証方法 | 期待結果（上がる確率・正解率・ベースライン / モデル戦略・買い持ち・売買回数） | 結果 | 備考 |
|---|---|---|---|---|
| 4-10 | 基本 / ホールドアウト（**改善前と同じ方式**） | 53.1%・52.4%・50.8% / -10.2%・11.7%・185回。条件表示は「ホールドアウト」「基本 11個」で、市場指数の表示はない | | |
| 4-11 | 基本 / ウォークフォワード | 53.1%・51.7%・50.8% / 7.1%・11.7%・181回 | | |
| 4-12 | 拡張 / ホールドアウト | 50.2%・52.5%・50.7% / 13.6%・10.9%・175回 | | |

> DEMO はランダムな値動きなので、本来は予測できません。それでも設定によってモデル戦略が -10% 〜 +14% と大きくぶれます。
> **1回の結果が良くても、それは偶然の可能性が高い**ことを確かめる項目です。実データでも、1銘柄・1期間だけで「改善した」と判断しないようにします。
